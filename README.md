# ☕ Velvet & Roast — Specialty Coffee & Urban Bakery

![Velvet & Roast Banner](https://images.unsplash.com/photo-1501339847302-ac426a4a7cbb?q=80&w=1200&auto=format&fit=crop)

A modern, high-performance, dark-mode web application built for **Velvet & Roast**, an artisanal specialty coffee house and urban bakery. The platform offers a seamless customer experience including an interactive menu with custom drink builders, single-origin whole bean retail shopping, online table reservations, and direct-to-barista WhatsApp checkout.

---

## ✨ Features

- **🎨 Nordic Minimalist & Dark Aesthetics**: Crafted with deep obsidian shades (`#0F0D0C`), glassmorphism cards, warm amber accents (`#D97706`), and premium typography (*Cormorant Garamond* & *Plus Jakarta Sans*).
- **☕ Interactive Menu & Customizer Modal**:
  - Filter by *Signature Drinks, Cold Brews, Hand Pours, Pastries, and Brunch*.
  - Customize milk options (Whole Milk, Oat, Almond, Soy, Pistachio) with dynamic pricing updates.
  - Tasting note tags and dietary badges (*Vegan*, *Gluten-Free*, *Barista Choice*).
- **🫘 Single-Origin Whole Bean Shop**:
  - Select roast profiles (Ethiopia Yirgacheffe, Colombia Huila, Brazil Cerrado).
  - Grind size selection (*Whole Bean, Espresso, V60, French Press*).
- **🛒 Dynamic Cart & Slide-out Drawer**:
  - Real-time subtotal, tax (8.875%), and barista tip calculator (0%, 10%, 15%, 20%).
  - Service type switcher (*Dine-In, Pickup, Local Delivery*).
  - One-click checkout that generates a structured order receipt sent directly via **WhatsApp**.
- **📅 Table Reservation System**:
  - Interactive guest count selector, date & time picker, and seating preferences (*Indoor Lounge, Sunlit Patio, Espresso Bar*).
- **📍 Live Store Status Indicator**:
  - Real-time "Open Now" / "Closed" status badge based on store operating hours.
  - Interactive Google Maps integration and location details.

---

## 🛠️ Tech Stack & Dependencies

- **HTML5**: Semantic and accessible markup structure.
- **Tailwind CSS (v3 CDN)**: Utility-first CSS framework for responsive layout and custom styling.
- **JavaScript (ES6+)**: Plain native JavaScript handling state management, cart logic, modal interactions, and WhatsApp payload generation.
- **Lucide Icons**: Clean, light, modern SVG icons.
- **Google Fonts**:
  - `Cormorant Garamond` (Elegant Serif for Headings)
  - `Plus Jakarta Sans` (Modern Sans-serif for UI & Body)
